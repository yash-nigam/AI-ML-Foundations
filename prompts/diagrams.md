OVERALL STYLE
- Clean, modern, professional educational infographic
- Premium technical-blog aesthetic
- Minimal flat-vector illustration style
- White or very light neutral background
- High visual clarity and strong hierarchy
- Suitable for a developer/AI/ML blog and LinkedIn
- Should feel like part of the SAME infographic series
- Avoid photorealism, 3D rendering, cartoonish styles, gradients-heavy UI, or decorative clutter

TYPOGRAPHY
- Use a clean modern geometric sans-serif font similar to Inter, Poppins, or Manrope
- Use the SAME font family throughout the image
- Main title: bold / extra-bold
- Section headings: bold
- Body text: regular / medium
- Example labels: medium / semi-bold
- Typography should be highly legible and consistent
- Use sentence case for descriptive text and ALL CAPS only for major category headings when appropriate
- Maintain consistent relative font sizes across all images

FONT HIERARCHY
- Main title: approximately 34–42 px, extra-bold
- Primary category heading: approximately 24–30 px, bold
- Secondary heading: approximately 18–22 px, bold
- Body text: approximately 15–18 px, regular
- Small labels/examples: approximately 13–16 px, medium
- Never use tiny unreadable text

COLOR PALETTE
Use a consistent restrained pastel-accent palette:

- Deep Navy: #173A70
- Green: #4FAF2F
- Light Green: #EAF5E2
- Blue: #2D9CDB
- Light Blue: #E7F3FB
- Purple: #7651C8
- Light Purple: #F0EAFB
- Orange: #F2A900
- Light Orange: #FFF3D9
- Red/Coral: #E94B4B
- Light Red: #FDE8E8
- Dark Text: #162033
- Secondary Text: #3E4652
- Background: #FFFFFF or #FAFBFC
- Border/Connector: #173A70 or a slightly lighter version of it

Use colors as accents rather than filling the entire canvas.
Keep the overall appearance light, clean, and professional.

SHAPES & COMPONENTS
- Use rounded rectangular cards
- Subtle thin borders
- Consistent corner radius across all cards
- Use circular icon containers above or inside major cards
- Keep spacing generous and symmetrical
- Use clean connector lines for relationships and hierarchy
- Maintain consistent stroke thickness
- Avoid unnecessary shadows; use only very subtle shadows when needed
- Cards should have a soft pastel background corresponding to their category color

ICONS & ILLUSTRATIONS
- Use simple flat-vector icons
- Icons should be minimal, geometric, modern, and professional
- Use consistent stroke weight
- Icons should match the same visual style across the entire series
- Do not mix realistic icons, emoji, 3D icons, or different illustration styles

LAYOUT
- Use a clear visual hierarchy from top to bottom or left to right
- Parent concepts should visually connect to child concepts
- Use alignment, spacing, and connector lines to make relationships immediately obvious
- Keep the composition balanced
- Avoid overcrowding
- Make the most important concept visually dominant
- Leave comfortable margins around the entire diagram
- Prefer symmetrical or intentionally balanced layouts

INFORMATION DESIGN
- Clearly distinguish parent concepts from child concepts
- Group related concepts visually
- Use color consistently to indicate conceptual relationships
- Every major concept should have a visually distinct card or node
- Keep explanations concise
- Use examples only where they improve understanding
- Prioritize readability over decorative elements

SERIES CONSISTENCY
This image will be one of MANY images in the same technical blog.

Therefore:
- Preserve the exact same visual language
- Preserve the same font family and typography hierarchy
- Preserve the same approximate font sizes
- Preserve the same color palette
- Preserve the same card shapes
- Preserve the same icon style
- Preserve the same connector style
- Preserve the same border thickness
- Preserve the same spacing philosophy
- Preserve the same background treatment
- Preserve the same professional flat-vector aesthetic

DO NOT invent a new visual style for each image.
